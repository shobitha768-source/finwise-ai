# FinWise AI

Build a fully functional, responsive, and beautifully styled "AI-Powered Financial Chatbot" web application using React, Tailwind CSS, and Lucide icons. The app should feature a modern, clean dashboard interface tailored for personal finance management, budgeting, savings, loans, investments, and financial planning.

### Core Features & Layout:

1. **Interactive AI Chatbot Interface (Main View)**

   - A clean chat window with a message history container, typing indicators, and a message input bar with send and quick-prompt buttons.

   - The chatbot must act as an intelligent financial advisor, providing structured, contextual answers to questions about budgeting, savings, loans, investments, and financial planning.

   - Include pre-built quick-action question chips (e.g., "How can I start a monthly budget?", "Compare fixed deposits vs mutual funds", "How do loan interest rates work?", "Tips for emergency fund savings").

   - Simulate realistic AI reasoning/responses with structured markdown support (bullet points, bold text, and currency formatting).

2. **Dashboard Overview Panel**

   - Summary metric cards displaying simulated user data: Total Balance, Monthly Savings Rate, Active Loans, and Investment Portfolio Value.

   - Visual charts or progress bars for monthly budgeting categories (Housing, Food, Entertainment, Savings, Debt).

3. **Built-in Financial Tools & Calculators (Tabs or Sidebar Navigation)**

   - **Budget Planner:** Input income and expenses to see a breakdown chart.

   - **Loan EMI Calculator:** Sliders for loan amount, interest rate, and tenure with calculated monthly payments.

   - **Investment Growth Simulator:** Compound interest calculator for long-term investments.

4. **"How AI is Used" Explanatory Modal / Section**

   - A dedicated information section or modal explaining the architecture behind the project (e.g., Natural Language Processing pipeline, intent matching, prompt structuring, and client-side financial computation models) to satisfy academic/project presentation requirements.

5. **Sample Data & Polish**

   - Pre-load the app with realistic sample user data so all dashboards, charts, and chatbot context are immediately interactive and populated upon loading.

   - Ensure a polished dark/light aesthetic, smooth transitions, and mobile-responsive layout.
